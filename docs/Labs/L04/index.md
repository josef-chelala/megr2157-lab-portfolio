Inspiration from [this tolerance found online](https://www.printables.com/model/1593984-tolerancefriction-fit-test), with additional help from professor to further develop


to test how deep a text should be engraved by giving different depths for different numbers. Saw multiple sources saying different minimum depth values, so I will start at +0.5 with .25mm and add .05mm for each number after. Since not enough for .8mm, I just added my name and made that a .8mm depth

Uncertain what percentage infill to use, I decided to base the percentage on what is used for benchy which [is about 10 to 15%](https://www.3dmakerengineering.com/blogs/3d-printing/the-power-of-the-3d-benchy).
